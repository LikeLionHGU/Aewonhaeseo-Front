기준치 조회가 규모별 항목까지 돌려줍니다

scale이 필수가 되면서, 배출규모에 따라 기준이 갈리는 BOD·COD·부유물질이 함께 나옵니다. 이전에는 규모와 무관한 세 항목만 왔습니다.

GET /standards/limits → 400 REQUEST_INVALID (scale 필수) GET /standards/limits?scale=small → 6개 항목 전부 WQ-001 max 80 WQ-002 max 50 WQ-004 max 80 ← 규모에 따라 달라짐 WQ-005 max 60 WQ-006 max 8 WQ-008 5.8~8.6 ← scale null (규모 무관) scale=large 로 바꾸면 WQ-001 60 · WQ-002 40 · WQ-004 60
클라이언트의 getStandardLimits도 scale을 필수 인자로 바꿨습니다.
정정

2차 보고 중 하나를 바로잡습니다

2차 때 "이 엔드포인트에는 scale 파라미터가 없다"고 적었는데 사실이 아닙니다. 스펙에는 처음부터 선택 파라미터로 선언돼 있었고, 응답만 보고 단정한 제 오류입니다. 실제 변경은 선택 → 필수이며 그와 함께 데이터가 채워졌습니다.
